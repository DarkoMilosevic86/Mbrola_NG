# Phoneme inventory = the Castilian SAMPA symbols of the es1 MBROLA voice
# (dumped from the database: 26 symbols, a complete diphone matrix), plus
# the five allophones that Spanish has and es1 does not distinguish: the
# approximants B D G of b d g ("abogado") and the syllable-final s2 and T2
# ("es", "feliz"). postlex.txt produces them, and the voices that have no
# separate sound for them map them back (catalog/catalog.json): es1
# "B=b D=d G=g s2=s T2=T". The Venezuelan voice vz1 has its own approximants
# and its own final s and uses them.
# The other Spanish voices are mapped to these symbols the same way.
#
# FORMAT:  symbol  type  duration  min-duration  partner  [features] [viseme=N]
#   type      vowel | consonant | pause   (exactly one pause phoneme)
#   duration  default duration in ms at normal rate
#   min       minimum duration in ms at high rates (intelligibility)
#   partner   voicing partner (p <-> b ...), "-" if none
#   features  free words, for documentation
# =============================================================================
