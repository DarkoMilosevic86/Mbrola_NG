# Numbers are always Spanish: mil, millón, mil millones ...
#
# FORMAT - rule-based number format (subset of ICU/CLDR RBNF syntax)
#   %name:            starts a ruleset (%%name: = private helper)
#   base: text;       rule for numbers >= base (up to the next rule)
#     <<              quotient (number / divisor), same ruleset
#     >>              remainder (number % divisor), same ruleset
#     <%set<  >%set>  the same with another ruleset
#     =%set=          the whole number with another ruleset
#     [ ... ]         left out when the remainder is 0
#     divisor = 10^(number of digits of base - 1)
#   -x: text;         negative numbers (>> = absolute value)
#
#   @plural CATEGORY: condition     CLDR plural rules (operands n i v f t)
#
# Three genders/forms are needed:
#   -masculine     standalone: "uno", "veintiuno"      (default)
#   -masculine-un  before a masculine noun: "un euro", "veintiún euros"
#   -feminine      "una libra", "doscientas páginas"
# The numbers with a written accent (dieciséis, veintidós, millón) are
# written out, because the accent is what makes the stress right.
# =============================================================================

@plural one: i = 1 and v = 0

# Ordinals: the stem (without the final -o / -a) for 0 to 20; the tens,
# hundreds and thousands are written out in the public rulesets, because
# both words are inflected ("vigésimo primero", "vigésima primera").
