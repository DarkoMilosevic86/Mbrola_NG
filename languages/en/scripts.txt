# Latin letters -> canonical lowercase letters. The apostrophe is treated
# as a LETTER so that "don't", "it's", "o'clock" stay one word and are found
# in lexicon.txt; g2p.txt reads it as nothing.
# Letters of other alphabets are unknown to English and skipped.
#
# SECTIONS (see languages/hr/scripts.txt for the full description)
#   [script NAME]  lower [Upper ...] -> canonical letters
#   [normalize]    text clean-up: from -> to ("" = delete)
# =============================================================================
