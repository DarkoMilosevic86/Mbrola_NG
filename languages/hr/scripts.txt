# Decision D1: Latin and Cyrillic are two spellings of the same sounds.
# Every letter is mapped to CANONICAL letters; lexicon, G2P rules, lists and
# abbreviations only ever see canonical text, so "ćirilica" and "ћирилица"
# give the same phonemes.
#
# Canonical alphabet: a b c č ć d đ e f g h i j k l m n o p r s š t u v z ž
#   plus q w x y (foreign letters) and the single-letter digraphs
#   ǆ ǉ ǌ used for Cyrillic џ љ њ (one letter = one sound), so that
#   Cyrillic "нј" (n + j) and "њ" stay different (ANALYSIS 7.6).
#
# SECTIONS
#   [script NAME]      lower [Upper ...] -> canonical letters
#   [homoglyphs NAME]  x -> y : in a word written mostly in script NAME, a
#                      look-alike letter x of another script becomes y
#   [normalize]        text clean-up before anything else: from -> to
#                      (longest match; "" = delete)
#   [lexkey]           canonical letter -> letters used for lexicon keys
# Characters may be written as U+XXXX.
# =============================================================================
