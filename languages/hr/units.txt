# Units and currencies after a number ("5 km", "5%", "20 °C") or - with the
# prefix flag - also before it ("€5", "EUR 5"). The number is read in the
# unit's gender and the unit in the plural form the number requires
# ("1 euro, 2 eura, 5 eura"; "1 kuna, 2 kune, 5 kuna").
#
#   @forms CATEGORIES               order of the form columns (CLDR names)
#   @gender NAME %ruleset           number ruleset for a gender
#   keys | gender | forms... [| flags]
#     keys    spellings separated by spaces (U+XXXX allowed)
#     gender  a @gender name, or - (default cardinal)
#     flags   prefix  (may stand before the number)
#             cs      (keys are case-sensitive)
# =============================================================================

@forms one few other
@gender m %spellout-cardinal-masculine
@gender f %spellout-cardinal-feminine
@gender n %spellout-cardinal-neuter
