# Character names for spelling / character mode (ANALYSIS 7.10). Cyrillic
# letters have the same Croatian names as their Latin counterparts.
#
# FORMAT:  characters | name [| spelled]   (lowercase; upper case is found
#                                           through scripts.txt)
#   name      the name in running text: this is what an acronym is read with
#             ("HDZ" -> "ha de ze", "5G" -> "pet ge")
#   spelled   the name in character / spelling mode (a screen reader going
#             through a word letter by letter, character echo). Text, or
#             phonemes between slashes. Left out: `name` is used there too.
#   @capital TEXT   said before a capital letter (host setting)
#   @unknown TEXT   said for a character without a name
#
# The consonants are spelled with a SCHWA ("bə cə də", not "be ce de"): the
# vowel is then only a carrier, the consonant itself carries the difference,
# which is what makes b/v/g/d/p/t/z distinguishable at speed. cr1 has no
# schwa, so the schwa phoneme @ (phonemes.txt) is realized as its vocalic r
# ("prst") through the voice's phoneme map - acoustically the closest thing
# to a schwa in this voice. The letter r is that schwa alone ("ər").
# To go back to a traditional name for one letter, delete its third field.
# =============================================================================
